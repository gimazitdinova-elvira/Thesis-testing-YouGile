# Thesis-testing-YouGile

# Дипломный проект: Автоматизация тестирования YouGile

Данный репозиторий содержит проект по автоматизации тестирования веб-приложения 
[YouGile](https://ru.yougile.com/) (система управления проектами и задачами). 
В рамках работы реализованы UI- и API-автотесты, покрывающие ключевые пользовательские сценарии.

## 🛠 Стек технологий
*   **Язык:** Python 3.10+
*   **Фреймворк для тестов:** Pytest
*   **UI-тестирование:** Selenium WebDriver
*   **API-тестирование:** Requests
*   **Отчетность:** Allure Framework

## 📂 Структура проекта
*   `config.py` — конфигурационный файл (URL, токены, логины/пароли).
*   `conftest.py` — общие фикстуры (запуск браузера, авторизация, заголовки для API).
*   `test_api.py` — API-автотесты (маркер `api`).
*   `test_ui.py` — UI-автотесты (маркер `ui`).
*   `requirements.txt` — список зависимостей проекта.
*   `pytest.ini` — настройки маркеров Pytest.
